# Bible services and replay boundaries

Prepared September 17, 2026 for Sherman G. Laing / Quantum.Earth.Laing.

| Service or process | What is included | What replay means |
| --- | --- | --- |
| Expanded verse studies | Recovered Genesis 1:1 through 1:5 prose and structured records, with the earlier Genesis 1:1 baseline | Read the existing complete studies, inspect their sources and calculations, and recompute declared word counts. The Genesis 1:1 expanded study contains exactly twice the baseline's words under the documented counting rule. |
| Hebrew letter arithmetic | Recovered historical WORD_CORE reference implementation and known-answer fixtures | Recompute supported declared schemes using explicit source spellings and normalization policies. The reference implementation's own clean-room label is preserved. |
| Study arithmetic checks | New replay integration around the recovered source and study records | Run deterministic checks and inspect machine-readable results. New integration is not presented as original historical code. |
| Bible web interface | Recovered historical interface and selected data, plus any explicitly labeled portable adaptation | Explore the included 34-verse Creation Week dataset and declared mappings. WEB data and KJV study quotations retain their distinct edition labels. |
| Bible governance and agent instructions | Recovered canon hierarchy, Word-alignment layer, Gospel training packet and calibration prompt | Inspect or reuse the published instruction workflow within the license. A policy instruction is not, by itself, a trained model or a measured guarantee of model behavior. |
| Original AI relationship | Preserved source documents describe the Bible-related directions and services associated with the research program | Their presence documents those services and instructions. It does not supply a provider's model weights or reproduce a past hosted-model response by rerunning model inference. |

The replay preserves a distinction between Scripture, exact source text, reading aid, declared calculation, linguistic explanation and interpretation. Arithmetic checks do not prove theological claims or establish divine endorsement of an algorithm.

Historical study text can be replayed as an exact recovered artifact. Regenerating prose through an AI model is a separate process; these files do not guarantee identical newly generated prose. The published workflow records the inputs and conventions needed to inspect and continue the study responsibly.

The complete original release ZIPs could not be downloaded during this recovery. Standalone files were recovered through complete text reads instead, with byte-count comparisons recorded. Absent historical implementations and unreplayed historical test totals must remain identified as such. This release does not silently substitute new code for missing original evidence.
