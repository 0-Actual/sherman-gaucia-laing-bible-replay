The original Genesis 1:1 baseline contains **5,386** whitespace-separated tokens. Its expanded version contains **10,772**, exactly **twice** that count. The later expanded studies retain the substantial long-study format; an exact twofold comparison to a separate shorter version of each is not asserted.

The dates above are the recovered Markdown artifacts’ creation timestamps. They do not establish the first inception of the method, a historical GitHub publication, or a public disclosure date. Exact UTC timestamps are preserved in [STUDY_CATALOG.json](STUDY_CATALOG.json).

Counts use `str.split()` on the complete Markdown file and the JSON `lesson_markdown` field. This count includes heading and formatting tokens. Genesis 1:3–1:5 include separate source or study notes, which explains the difference between the two columns. Original preaching counts remain labeled as historical validation fields; the catalog does not reinterpret their boundaries.

Each study contains the Hebrew display, transliteration, KJV verse, declared letter-value convention, detailed calculations, New Testament witnesses, and extended Christian exposition. The original source notes distinguish externally consulted texts from passages transcribed from model textual knowledge. Recovery did not upgrade those notes into an independent textual collation.
